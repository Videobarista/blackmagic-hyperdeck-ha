# Brand assets

Placeholder folder for community-contributed branding (e.g. a nicer icon, a wordmark for docs/screenshots).

No Blackmagic-related logo is included here by the maintainer, to avoid any copyright issues with Blackmagic Design's own branding and trademarks. If you'd like to contribute something appropriate (a generic tape-deck/HyperDeck-style icon, not Blackmagic's own logo or product photography), a pull request adding it here is welcome.

Note: this is separate from `custom_components/blackmagic_hyperdeck/brand/`, which holds the actual `icon.png` HACS/Home Assistant look for (a small generic placeholder icon, not a Blackmagic logo). This folder is for anything more/better that the community wants to add.
