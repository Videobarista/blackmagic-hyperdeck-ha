# Brand images

Home Assistant 2026.3 and later reads brand images from this folder, taking
priority over the brands CDN. Nothing needs to be configured.

Shipped here:

- `icon.png` — 256x256 px
- `icon@2x.png` — 512x512 px

Both are an original, generic design made for this project, not the
Blackmagic Design logo. Replace them with your own PNGs of the same names and
sizes if you prefer different artwork. Other supported names are
`dark_icon.png`, `logo.png`, `dark_logo.png` and their `@2x` variants.
